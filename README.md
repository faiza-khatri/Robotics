# Vision-Guided Autonomous Pick-and-Place Using a 4-DOF Serial Manipulator

A fully autonomous vision-guided pick-and-place system developed for **EE/CE-366L: Introduction to Robotics Lab, Habib University (2026)**.

The project uses a **PincherX-100 (Phantom X Pincher)** 4-DOF serial manipulator and an overhead Intel RealSense RGB-D camera to detect, localize, grasp, and sort colored blocks without human intervention.

Most details are provided in the uploaded final report pdf
